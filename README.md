# Splash Designer

水風呂の写真や水面に触れて遊び、短い動画として共有することを目指す、
Canvas 2Dベースの体験型Webアプリです。

現在は、独自EngineとSceneManagerからEntranceSceneを起動し、暖簾から浴室へ
入る体験、音声、水面反射、長押しオーバーフロー、クレジット、入場前ガイドを
実装済みです。左壁を窓と排水グレーチングへ変更するIssue-0023と、赤外線センサー
によるバイブラを実装したIssue-0011は、Netlifyプレビューで確認済みです。

## 現在実装されている体験

- 画面サイズと端末ピクセル比に追従するCanvas
- タップでは片側を軽くめくり、スライドでは移動方向の片側だけを払う暖簾操作
- 慣性と距離拘束を使った暖簾の布変形
- 布と一緒に変形する印刷テクスチャと、入口右下のクレジット表記
- 暖簾の消失、暗い間、浴室のフェードイン
- 人の目線で満水の浴槽を見下ろす構図と、手前の2段床・手すり
- 状態を保持・伝播するリザバー型水面
- 風を受けたように不規則な場所から生まれる、待機中の微細な水面の揺れ
- 奥ヘリの赤外線センサーから起動する、1分間の高密度な泡・水面振動・ループ音
- 水面の長押しから浴槽四辺、2段の路段、最下部の路面へ流れる最大3重のオーバーフローと落水音
- 暖簾操作を起点としたブラウザ音声のアンロック
- 暖簾の布音、浴室環境音、遠くの桶音
- 勢いよく暖簾を払った場合だけ鳴る隠し歓迎音声
- 音源提供元を確認できるクレジット表示

## ローカル起動

ビルド工程やパッケージのインストールは不要です。ES Modulesを使用しているため、
`index.html`を直接開かず、ローカルHTTPサーバー経由で起動します。

```sh
cd SplashDesigner
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで次のURLを開きます。

```text
http://127.0.0.1:4173/
```

## 実行経路

```text
index.html
  → main.js
    → Engine
      → SceneManager
        → EntranceScene
```

`Game.js`とPhaser版`SplashScene`は過去のデモ実装です。現在の起動経路では
使用していませんが、参照状況を精査するまでは削除しません。

`ARCHITECTURE.md`を参照してください。
